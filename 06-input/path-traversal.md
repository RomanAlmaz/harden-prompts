# Пути к файлам

Если имя файла или кусок пути приходит снаружи и склеивается с каталогом, чтение и запись уезжают из этого каталога. Опасно и для скачивания, и для шаблонов, и для логов.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| `base + имя от пользователя` | Открывается файл вне каталога |
| Проверка по строке `../` вырезанием | Остаются обходы через кодировку и повтор |
| Симлинк внутри каталога указывает наружу | Проверка префикса пути врёт |
| Имя файла управляет архивом, который распаковывают | Запись идёт вне папки распаковки |
| Шаблон или include выбирается параметром | Исполняется не тот файл |

## Сделать

1. Не принимать путь. Принимать id файла и искать путь в своей таблице.
2. Если имя всё же нужно: взять только базовое имя, выкинуть разделители, собрать путь API файловой системы и проверить, что итоговый реальный путь остаётся внутри ожидаемого каталога.
3. Не вырезать `../` в цикле как единственную защиту.
4. Распаковка архивов: запрет абсолютных путей и выхода из каталога, лимит числа и размера файлов, отказ от симлинков.
5. Выбор шаблона и отчёта - белый список id, не путь.
6. Права процесса не должны читать домашние каталоги и секреты системы просто потому, что он умеет открывать файлы.

## Промпт

```text
Найди склейку путей с пользовательским вводом: скачивание, загрузка, шаблоны, распаковка, логи.

Перейди на id файла в своей базе. Где имя необходимо, бери только базовое имя и проверяй итоговый канонический путь на пребывание внутри нужного каталога.
Архивы распаковывай с лимитом и без выхода из папки. Шаблоны выбирай по белому списку.

Не добавляй примеры обхода пути и не читай файлы вне проекта ради демонстрации.
```

## Готово, когда

- [ ] Путь к секретному или системному файлу не собирается из ввода
- [ ] Id файла решается на сервере
- [ ] Архивы не пишут наружу каталога
- [ ] Шаблоны выбираются из списка
