# Запрос сервера по чужому URL

Функции «скачай по ссылке», «превью», «вебхук клиента» и «импорт аватара» заставляют сервер сходить туда, куда указал человек. Так сервер становится клиентом внутренней сети, облачных метаданных и чужих файлов.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| URL целиком от пользователя, сервер его открывает | Сервер ходит во внутренние адреса и служебные API облака |
| Адрес проверили, а HTTP-библиотека сама пошла по редиректу | Второй адрес уже внутренний, проверка первого ничего не дала |
| Разрешён не только `https` | Читаются локальные и псевдо-схемы |
| DNS разобрали один раз, соединились со следующим ответом | Имя после проверки указывает иначе |
| Ответ внутренний отдают пользователю или кладут в PDF | Человек читает то, что видит сервер |
| Вебхук клиента бьёт по произвольному хосту без списка | Так рассылают запросы от имени компании |

## Сделать

1. По возможности не ходить по URL от пользователя. Принимать загрузку файла или id уже известного объекта.
2. Если хождение нужно: только `https`, белый список хостов в конфиге, запрет адресов петли, частных сетей, link-local и служебных имён. Разрешение имени и соединение - с той же проверкой адреса, без слепого редиректа.
3. Редиректы либо запретить, либо проверять каждый следующий адрес теми же правилами.
4. Таймаут, лимит размера, не отдавать сырое тело внутреннего ответа клиенту.
5. Секреты приложения и заголовки внутренней авторизации не пересылать в этот запрос.
6. Вебхуки продукта: хост из белого списка или отдельная проверка при сохранении URL, не в момент массовой рассылки без лимита.

## Промпт

```text
Найди серверные HTTP-вызовы, где адрес цели зависит от пользователя: превью ссылок, импорт по URL, вебхуки, аватары.

Убери произвольный URL, если хватает загрузки файла. Иначе оставь только https и белый список хостов, запрети частные, петлевые и link-local адреса, проверяй каждый редирект, поставь таймаут и лимит размера.
Не пересылай внутренние секреты и не возвращай сырое тело такого ответа человеку.

Не составляй список целей для проверки внутренних адресов и не ходи с сервера в боевую внутреннюю сеть ради демонстрации.
```

## Готово, когда

- [ ] Произвольный URL не открывается сервером без списка хостов
- [ ] Редиректы не уводят проверку
- [ ] Служебные и частные адреса запрещены
- [ ] Внутренние заголовки не утекают в этот запрос
