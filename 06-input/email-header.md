# Заголовки писем

Поля «кому», «тема» и имя вложения - заголовки письма. Перевод строки в таком поле добавляет новые заголовки и меняет получателя или содержимое.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Тема, имя или адрес собраны склейкой сырого SMTP | Ввод добавляет своих получателей и заголовки |
| Адрес не проверен библиотекой | Письмо уходит не туда |
| Вложение получает имя от пользователя без очистки | Почтовый клиент получает неожиданное имя |
| Тело HTML письма - это непроверенный HTML | Получатель открывает активную разметку. См. `xss.md` |
| Ошибки SMTP с адресами пишутся в ответ API | Чужие адреса становятся видимы |

## Сделать

1. Собирать письмо через API библиотеки: отдельные поля «кому», «тема», «тело». Не склеивать сырой текст письма.
2. В полях заголовков запретить перевод строки и управляющие символы. Отклонять такое значение, а не вырезать молча половину.
3. Адрес проверять парсером адресов, один адресат там, где продукт ждёт одного.
4. HTML письма - своим шаблоном с экранированием, не сырая строка из формы. См. `ssti.md`.
5. Имя вложения - базовое имя без пути и без перевода строки.
6. Лимит писем. См. `08-api/rate-limit.md`.

## Промпт

```text
Проверь отправку почты.

Собирай письмо полями библиотеки, не сырой строкой SMTP.
Отклоняй перевод строки в теме, имени и адресе. Адрес разбирай парсером.
HTML письма экранируй. Имя вложения очисть до базового имени.
Не возвращай клиенту сырой диалог SMTP.

Не добавляй примеры заголовков и не рассылай письма на боевые ящики.
```

## Готово, когда

- [ ] Письмо не собирается склейкой сырого SMTP
- [ ] Перевод строки в заголовках отклоняется
- [ ] HTML письма экранирован
- [ ] Сырой ответ SMTP не уходит клиенту
