# Проверка входных данных

Проверка на сервере режет мусор и неожиданные типы до того, как они попадут в запрос, файл или письмо. Проверка в браузере нужна человеку, а не защите: её нет, когда зовут API напрямую.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Правила только в HTML | API принимает то, что форма не показала бы |
| Схема «лишние поля разрешены» | В модель падают роль, цена, владелец |
| Строка там, где ждут число или id | Дальше строка склеивается в запрос или путь |
| Нет верхнего предела длины | Огромное тело забивает память и логи |
| Свободный HTML сохраняется как есть | Позже он исполняется у другого человека |
| Ошибка валидации возвращает внутреннее выражение фильтра | Наружу торчит устройство данных |

## Сделать

1. На каждом входе сервера: тип, длина, диапазон, формат, белый список значений для статусов и ролей. Отдельная схема на запись, не общая «модель таблицы».
2. Неизвестные поля отбрасывать или отклонять запрос.
3. Лимит размера тела, глубины JSON и числа элементов в списке.
4. Нормализовать Unicode там, где сравниваются почта и имена, и делать это до проверок, один раз.
5. HTML от людей не хранить как безопасный, если нет отдельного санитайзера с белым списком тегов. См. `xss.md`.
6. Падения проверки - обычная ошибка 400 без стека и без эха всего объекта.
7. Те же правила для очереди, вебхука и импорта файла. «Внутреннее» сообщение тоже вход.

## Промпт

```text
Поставь серверную проверку входных данных на границах приложения.

Для каждого внешнего входа задай схему: типы, длины, диапазоны, белый список статусов. Лишние поля не записывай в модель.
Ограничь размер тела и вложенность. Браузерную проверку оставь для удобства, но не считай её контролем.
Ошибки не должны возвращать стек и сырой объект.
Очереди, импорт и вебхуки проходят ту же строгость.

Не добавляй список атакующих строк. Если схемы уже есть, ужесточи их, не создавай вторую параллельную систему без нужды.
```

## Готово, когда

- [ ] У внешних входов есть серверная схема
- [ ] Лишние поля не меняют модель
- [ ] Есть предел размера
- [ ] Ошибка проверки не раскрывает внутренности
