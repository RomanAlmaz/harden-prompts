# Межсайтовый скрипт в выводе

Опасно не «слово script в базе», а то, что чужой текст попадает в страницу как код. Лечится контекстом вывода: HTML, атрибут, URL и скрипт кодируются по-разному.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Текст человека вставлен в HTML без кодирования | Браузер исполняет его как разметку |
| `innerHTML`, `dangerouslySetInnerHTML`, сырой шаблон | Фреймворк перестаёт экранировать |
| Текст закодирован для HTML и вставлен в атрибут или URL | Кодировка не того контекста |
| Богатый текст без белого списка тегов | В сохранённой статье живёт активная разметка |
| Данные вставлены внутрь `<script>` склейкой | Строка вырывается в код |
| DOM строится из `location`, `document.referrer` или postMessage без проверки | Страница исполняет то, что пришло в браузер |

## Сделать

1. Шаблоны фреймворка с автоэкранированием по умолчанию. Места, где экранирование выключено, перечислить и обосновать.
2. Не собирать HTML конкатенацией. Для текста - текстовый узел или экранирование контекста.
3. Богатый текст: библиотека-санитайзер с белым списком тегов и атрибутов, на сервере, при сохранении и при выводе. Стили и ссылки тоже из белого списка. `javascript:` в ссылках не оставлять.
4. JSON внутри HTML вставлять штатным образом фреймворка, не сырой вставкой в скрипт.
5. URL для перехода проверять: разрешены только ожидаемые схемы, обычно `https`.
6. CSP как второй слой, см. `04-transport/csp.md`. Не вместо экранирования.
7. Cookie сессии с `HttpOnly`, чтобы успешный XSS хотя бы не прочитал пропуск. Это не лечит сам XSS.

## Промпт

```text
Найди места, где данные человека или из URL попадают в HTML, атрибут, URL или скрипт.

Оставь автоэкранирование шаблонов. Убери innerHTML и аналоги на небезопасных данных. Где богатый текст нужен, пропусти его через санитайзер с белым списком на сервере.
Запрети опасные схемы URL. Не вставляй JSON в скрипт склейкой.
CSP подключи по файлу csp, но не вместо кодирования вывода.

Не добавляй примеры вредоносной разметки в код, тесты и отчёт. Тест может проверять, что опасная схема URL отклоняется, без коллекции payload-ов.
```

## Готово, когда

- [ ] Обычный текст не может стать разметкой
- [ ] Выключенное экранирование найдено и убрано или обосновано
- [ ] Богатый текст проходит санитайзер
- [ ] Ссылки не принимают произвольную схему
