# Вызов программ и оболочки

Если оболочка разбирает строку, любой кусок ввода может стать второй командой. Вызов с массивом аргументов передаёт ввод как данные, пока программа сама не начинает их интерпретировать.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| `shell=True`, `system`, `exec` строки, обратные кавычки | Ввод пользователя разбирает оболочка |
| Имя программы или флаг собираются из ввода | Запускается не та программа |
| Путь к рабочей папке приходит снаружи | Процесс работает в чужом каталоге |
| Ошибка возвращает stdout внутренней утилиты | Наружу утекает лишнее |
| Сервис крутится от администратора машины | Удачный вызов получает всю машину |

## Сделать

1. Не звать оболочку. Запускать программу списком аргументов, без строки для `sh`/`cmd`.
2. Имя программы - константа из кода. Аргументы-переключатели - из белого списка. Пользовательский текст передавать одним аргументом, не склеенной строкой.
3. Если хватает библиотеки языка, не звать внешнюю программу.
4. Таймаут, лимит размера вывода, не наследовать лишние переменные среды и секреты.
5. Процесс приложения не от root, если это возможно в этой поставке.
6. Найти `shell=True`, `os.system`, `child_process` со строкой, `Process` со `cmd.exe /c` и убрать ввод оттуда.

## Промпт

```text
Найди запуск внешних программ и оболочки. Убери разбор пользовательского ввода оболочкой.

Запускай процесс списком аргументов. Имя программы и флаги - из констант или белого списка.
Поставь таймаут. Не отдавай клиенту сырой вывод системных утилит.
Не расширяй права процесса.

Не добавляй примеры вредоносных команд и не запускай разрушительные проверки на машине.
```

## Готово, когда

- [ ] Нет вызова оболочки со склеенной строкой ввода
- [ ] Имена программ не приходят от пользователя
- [ ] Есть таймаут на внешний процесс
- [ ] Сырой системный вывод не уходит клиенту
