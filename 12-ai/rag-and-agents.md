# Поиск по документам и агенты с инструментами

Документ в индексе и ответ инструмента - такой же недоверенный ввод, как комментарий пользователя. Агент не должен звать платёж, почту или чужую базу только потому, что так написано в найденном абзаце.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Индекс содержит чужие документы, а фильтр прав делается после поиска или никак | В ответ попадает чужой текст |
| Найденный текст считается инструкцией агенту | Документ заставляет вызвать инструмент |
| Инструмент «выполни запрос» или «прочитай URL» без списка | Агент читает внутренние адреса и всю базу |
| Слишком широкие права ключа модели | Обычный чат действует как админ интеграции |
| В индекс кладут секреты из тикетов | Их потом цитирует ответ |
| Нет следа, какой инструмент сработал | Нельзя понять, кто что сделал |

## Сделать

1. Поиск фильтрует по правам того человека, который спрашивает, до того как текст попадёт в промпт. Общий индекс без меток доступа для разных клиентов не использовать.
2. Найденные куски помечать как цитаты-данные, не как системные правила.
3. Инструменты: белый список функций, схема аргументов, та же авторизация, что у API. Нет универсального «выполни SQL» и нет произвольного URL. См. `ssrf.md`.
4. Ключ интеграции с минимальными правами, отдельный от админского.
5. Не индексировать секреты и лишние персональные данные. Удаление документа у человека удаляет или исключает его из индекса.
6. Журнал вызовов инструментов без содержимого секретов.

## Промпт

```text
Если есть RAG или агент с инструментами, закрой доступ к чужим документам и лишние действия.

Фильтр прав ставь в поиск до промпта. Текст документов не делай системной инструкцией.
Инструменты ограничь белым списком и обычными проверками прав. Убери произвольный SQL и произвольный URL.
Ключ модели не должен быть ключом админа. Секреты не индексируй.
Пиши журнал вызовов без секретов.

Если RAG и агентов нет - не добавляй их ради этого файла.
```

## Готово, когда

- [ ] Чужой документ не попадает в контекст
- [ ] Инструменты не шире, чем API у этого пользователя
- [ ] Нет произвольного URL и произвольного SQL от модели
- [ ] Удаление данных учитывает индекс
