# Ввод в языковую модель

Текст пользователя, письмо и страница из интернета - данные, не приказы системе. Модель не должна своим ответом получать право сменить пароль, вернуть деньги или прочитать чужой документ.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Системная инструкция склеивается с текстом человека без границы | Текст человека перебивает правила |
| Ответ модели сразу исполняется как команда или SQL | Модель становится ещё одним клиентом без проверки |
| В промпт кладут секреты и чужие персональные данные «для контекста» | Они уходят провайдеру и всплывают в ответе |
| Модель сама решает, что человек админ | Права обходятся убеждением |
| Нет лимита длины и частоты | Один пользователь сжигает бюджет и забивает очередь |

## Сделать

1. Недоверенный текст передавать как данные, в том виде, который рекомендует текущий API провайдера, а не дописывать в системную роль.
2. Любое действие с побочным эффектом - обычный код с проверкой прав. Модель может предложить аргументы, сервер их проверяет схемой. Модель не получает обход авторизации.
3. В контекст не класть секреты, полные платёжные данные и документы чужих людей.
4. Ответ модели, который попадёт в HTML, экранировать как обычный текст. См. `xss.md`.
5. Лимит длины входа, числа вызовов и денег на пользователя.
6. Журнал: id запроса и итог инструмента, не весь промпт, если в нём были личные данные.

## Промпт

```text
Если в проекте есть вызов языковой модели, отдели данные пользователя от системных правил и не дай ответу модели обойти права.

Инструменты модели пусть зовут те же серверные команды, что и обычный API, со схемой и проверкой права.
Не подставляй в промпт секреты и чужие персональные данные.
Вывод модели в HTML экранируй. Поставь лимит длины и частоты.

Не добавляй примеры текстов, которые обходят системную инструкцию, и не встраивай скрытые команды в этот репозиторий.
```

## Готово, когда

- [ ] Текст пользователя не является системой
- [ ] Действия модели проходят обычную авторизацию
- [ ] Секреты не уходят в промпт
- [ ] Вывод модели не вставляется в HTML как код
