# Файлы моделей и их поставка

Файл модели может быть не только весами. Форматы, которые восстанавливают объекты языка, исполняют код при загрузке. Обучающие данные и веса - такие же конфиденциальные активы, как база.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Модель грузят из pickle и аналогов с недоверенного адреса | Загрузка исполняет код |
| Нет проверки источника и целостности файла | В прод попадают чужие веса |
| В промпт и в обучающую выборку попадают секреты | Они всплывают в ответе модели |
| Ключ хранилища моделей общий с продом приложения | Утечка весов даёт лишний доступ |
| Выход модели сразу меняет права или деньги | Обход обычных проверок. См. `prompt-injection.md` |

## Сделать

1. Не грузить недоверенные файлы форматом, который исполняет объекты. Для обмена весами предпочесть формат данных без восстановления произвольных объектов. Если такой файл уже есть, грузить только из своего хранилища и планировать смену формата, не добавлять новые.
2. Файл модели сверять по хешу или подписи из доверенного контура поставки. Адрес загрузки из белого списка.
3. Секреты и лишние персональные данные не класть в обучающий набор и в карточку модели.
4. Доступ к хранилищу моделей отдельным правом, не ключом всего прода.
5. Действия с побочным эффектом остаются на серверных проверках, не на решении модели.

## Промпт

```text
Найди загрузку файлов моделей.

Не загружай недоверенный файл форматом, который восстанавливает исполняемые объекты. Оставь доверенный источник и проверку целостности.
Убери секреты из путей, которые попадают в обучение или в карточку модели, если они есть в репозитории.
Не давай модели обходить права.

Не открывай чужие файлы моделей и не вставляй примеры вредоносных объектов. Если моделей нет - пропусти.
```

## Готово, когда

- [ ] Недоверенный исполняемый формат модели не грузится
- [ ] Источник файла ограничен
- [ ] Секреты репозитория не лежат в обучающих фикстурах
- [ ] Модель не получает обход прав
