# Ключи шифрования

Шифр бесполезен, если ключ лежит рядом с данными, в репозитории или один на все задачи. Смена алгоритма должна быть заложена заранее: свой шифр и «самодельный постквантовый» не использовать.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Ключ в коде, в той же базе или в том же бэкапе | Утечка данных сразу читается |
| Один ключ на пароли, сессии, карты и бэкапы | Компрометация одной задачи вскрывает остальные |
| Нет версии ключа | Нельзя повернуть ключ и прочитать старые данные |
| Ключ в памяти логируется при ошибке | Журнал становится копией ключа |
| Алгоритм зашит без идентификатора | Позже нельзя понять, чем зашифрован столбец |

## Сделать

1. Ключи в KMS или секрет-хранилище. Приложение просит операцию или короткий доступ, а не хранит мастер-ключ в репозитории.
2. Отдельный ключ на отдельную задачу: сессии, токены TOTP, поля базы, бэкапы. Разные среды - разные ключи.
3. Рядом с шифртекстом хранить идентификатор ключа и алгоритма. Расшифровка не угадывает алгоритм.
4. Ротация: новый ключ для новых данных, старый только на чтение, пока данные не переписаны. Срок и владелец ключа записаны.
5. Постквантовые схемы не изобретать. Если регулятор или платформа уже даёт готовый алгоритм, использовать его. Иначе оставить обычный AEAD из `encryption.md` и пометку, что смена алгоритма возможна за счёт идентификатора.
6. В лог, ошибку и отчёт ключ не попадает.

## Промпт

```text
Проверь, где живут ключи шифрования и подписи.

Убери их из кода и из той же базы, что данные. Разведи ключи по задачам и средам.
Храни идентификатор ключа рядом с шифртекстом. Не выдумывай свой алгоритм и не включай экспериментальный шифр без готовой библиотеки платформы.
Ротацию опиши в коде только если хранилище это уже умеет. Иначе оставь пункт человеку.
Ключ не логируй и не вставляй в отчёт.
```

## Готово, когда

- [ ] Мастер-ключа нет в git и рядом с шифртекстом
- [ ] У шифртекста есть идентификатор ключа
- [ ] Разные задачи не делят один ключ без причины
- [ ] Свой шифр не добавлен
