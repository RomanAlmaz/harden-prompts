# Журналы и тревоги

Журнал должен показывать, кто сделал опасное действие, и не должен хранить пароль. Журнал, который можно переписать одним запросом приложения, бесполезен после взлома этой же учётки.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| В лог пишут тело запроса, заголовок авторизации, cookie, карту | Журнал становится складом секретов |
| Нет следа входа, отказа в праве, смены роли и платежа | Потом нечего разбирать |
| Строка лога собирается из ввода без очистки перевода строки | Запись журнала подделывается второй строкой |
| Приложение может удалить свой аудит | Следы пропадают |
| Часы плавают | События разных сервисов не сложить |
| Тревоги нет даже на всплеск отказов во входе | Узнают от пользователей |

## Сделать

1. Редакция секретов в одном месте логгера, не надеждой на память.
2. События безопасности: вход успех и отказ, выход, смена пароля, смена роли, отказ в праве, платёж, вебхук, админское действие. Поля: время в UTC, субъект, действие, объект, итог, источник. Не сам секрет.
3. Ввод в сообщениях лога не должен вставлять перевод строки и управляющие символы как есть.
4. Аудит пишется туда, куда обычная учётка приложения не может его стереть, если платформа это позволяет. Иначе - пункт человеку.
5. Не логировать лишнее персональное. См. `privacy.md`.
6. Хотя бы один сигнал: всплеск неудачных входов или шквал отказов подписи вебхука. Куда слать - решает человек, в коде оставить крючок.

## Промпт

```text
Приведи журналы в порядок.

Вырежи из логов пароли, токены, cookie, номера карт и сырые платёжные тела.
Добавь события безопасности без этих секретов: вход, смена прав, отказ авторизации, платёж, вебхук.
Очисти переводы строк во вводе, который попадает в текст лога.
Не дай обычному пути приложения молча стирать аудит; если это настройка платформы - напиши человеку.
Предложи один сигнал тревоги на всплеск неудачных входов, без рассылки в неизвестный мне канал: вынеси адрес в конфиг.

Не включай в отчёт фрагменты боевых логов с личными данными.
```

## Готово, когда

- [ ] Секреты не пишутся в лог
- [ ] Важные действия оставляют след
- [ ] Ввод не ломает строки журнала
- [ ] Есть место, куда повесить тревогу
