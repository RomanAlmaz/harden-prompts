# Личные данные

Чем меньше данных, тем меньше утечка. Этот файл не заменяет юриста и не делает продукт «соответствующим GDPR» или 152-ФЗ. Он убирает технические привычки, из-за которых данные текут шире, чем нужно продукту.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Профиль, логи и аналитика собирают лишнее | Утечка шире, чем функция |
| Ответ API отдаёт всю модель пользователя | Телефон и адрес уезжают на экран, где они не нужны |
| Поиск и ошибки содержат чужие персональные данные | Они попадают в мониторинг |
| Нет удаления или выгрузки по запросу человека, хотя продукт обещает | Копия живёт в бэкапе и в рассылке |
| Общий доступ к продакшен-базе у всех разработчиков | Лишние люди читают данные |
| Письмо поддержки содержит дамп профиля | Данные оседают в тикете |

## Сделать

1. Список: какие поля зачем, где хранятся, кто читает, сколько живут. Поля без цели не собирать в новых формах.
2. Ответы API отдавать проекцией под экран, не всей таблицей.
3. Журналы и аналитика без содержимого писем, документов, паролей и полных платёжных данных. Идентификатор пользователя вместо набора полей, где этого хватает.
4. Удаление аккаунта должно гасить сессии и убирать данные из основного хранилища. Бэкапы и сторонние рассылки перечислить отдельно: их часто не удаляет один `DELETE`.
5. Доступ разработчиков к боевым данным - исключение с причиной, не обычный способ отладки. Для отладки - обезличенные дампы.
6. Не писать в этот отчёт реальные персональные данные из базы.

## Промпт

```text
Сократи лишние персональные данные в коде, ответах API и логах.

Составь список полей профиля и где они отдаются. Убери из ответов то, что экрану не нужно.
Вычисти содержимое сообщений, документы и секреты из логов.
Проверь удаление аккаунта: сессии, основное хранилище, что останется в бэкапе и у почтового провайдера - отдельным пунктом человеку.
Не утверждай юридическое соответствие. Не копируй живые персональные данные в отчёт.
```

## Готово, когда

- [ ] API не отдаёт лишние поля профиля
- [ ] Логи не содержат содержимое личных данных и секреты
- [ ] Удаление аккаунта гасит сессии и основную запись
- [ ] Юридические обещания не выданы за сделанный комплаенс
