# Случайные значения

Токен, сессия, сброс пароля и CSRF должны быть непредсказуемы. Обычный генератор «для игр и выборок» предсказуем. Время и счётчик тоже.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Секрет из `Math.random`, `rand()` или аналога без CSPRNG | Токен угадывают или восстанавливают |
| Секрет из времени, id пользователя или счётчика | Следующее значение видно из предыдущего |
| Слишком короткий токен | Перебор дешевле, чем кажется |
| UUID версии 1 или самодельный «случайный» id без проверки версии | В идентификаторе время и адрес, а не только случайность |
| Один и тот же seed в тестах попал в прод | Все «случайные» значения известны |

## Сделать

1. Секреты генерировать только CSPRNG платформы. Не использовать генератор для симуляций.
2. Длина: id сессии не меньше 64 бит, цель 128. Токен сброса и CSRF не меньше 128 бит. См. `02-session/session.md` и `01-authentication/password-reset.md`.
3. Идентификаторы публичных объектов могут быть UUID версии 4 или другим случайным id. Не считать случайность заменой проверки прав.
4. Тестовый фиксированный генератор не подключать в боевой сборке.
5. Найти генераторы в коде выпуска токенов и заменить, если они не криптографические.

## Промпт

```text
Найди генерацию токенов, сессий, кодов и CSRF.

Оставь только CSPRNG платформы. Убери время, счётчик и обычный random из этих значений.
Проверь длину: id сессии не короче 64 бит, цель 128; токен сброса и CSRF не короче 128 бит.
Случайный id не заменяет проверку прав.
Тестовый генератор с фиксированным зерном не должен работать в проде.

Не пиши восстановление генератора и не печатай боевые токены.
```

## Готово, когда

- [ ] Секреты идут из CSPRNG
- [ ] Сессия не короче 64 бит, цель 128; сброс и CSRF не короче 128 бит
- [ ] Боевой код не использует тестовое зерно
- [ ] Случайный id не считается правом доступа
