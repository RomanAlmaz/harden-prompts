# Целостность HTTP-запроса

Прокси и приложение должны одинаково понимать, где кончается запрос. Два конфликтующих заголовка длины или тихое понижение версии протокола оставляют зазор, в котором один видит один запрос, а второй - другой.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Одновременно приходят два разных указания длины тела | Прокси и приложение расходятся, где граница запроса |
| Версию HTTP понижают без нормализации | Разбор на бэкенде другой, чем на входе |
| Лишние или повторяющиеся служебные заголовки проходят как есть | Смысл запроса зависит от того, какой заголовок прочитали |
| Приложение смотрит заголовки, которые должен был стереть только прокси | Клиент подставляет внутренний адрес и схему |

## Сделать

1. Принимать внешний HTTP на одном доверенном прокси. Приложение слушает не весь интернет напрямую, если перед ним уже есть этот прокси.
2. Отклонять запрос, в котором указания длины тела противоречат друг другу. Не чинить такой запрос угадыванием.
3. Понижение версии протокола делать только штатной связкой прокси и приложения одной поддерживаемой версии. Не писать свой разбор первой строки и длины.
4. Прокси стирает входные заголовки, которыми приложение определяет клиентский адрес, исходную схему и имя хоста, и ставит свои. Список этих заголовков явный.
5. Лимит размера заголовков и тела. Таймаут медленного клиента.

## Промпт

```text
Проверь границу HTTP между прокси и приложением по файлам конфига в репозитории.

Запросы с противоречивыми указаниями длины тела должны отклоняться, а не угадываться.
Не пиши свой парсер HTTP. Оставь разбор библиотеке и прокси.
Внутренние заголовки клиента, из которых читается адрес и схема, стирай на входе и выставляй заново.
Поставь лимит размера заголовков и тела, если его ещё нет в конфиге приложения.

Не добавляй примеры неоднозначных запросов и не поднимай боевой прокси. Если прокси живёт вне репозитория, перечисли, что должен проверить человек.
```

## Готово, когда

- [ ] Противоречивая длина тела не принимается
- [ ] Своего парсера HTTP нет
- [ ] Заголовки исходного адреса выставляет только доверенный прокси
- [ ] Есть лимит размера
