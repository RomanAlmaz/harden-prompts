# GraphQL

Один эндпоинт не значит одна проверка. Каждый резолвер решает, можно ли читать поле. Глубокий запрос без лимита кладёт сервер сам по себе.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Право проверили в корне, а вложенный объект нет | Через связь достают чужой узел |
| Интроспекция и консоль открыты на проде | Видна вся модель |
| Нет лимита глубины и сложности | Один запрос порождает тяжёлую работу |
| Ошибки резолвера возвращают стек | Видно внутренности |
| Мутация без того же CSRF-контроля, если сессия на cookie | Чужой сайт шлёт мутацию |
| Батч из многих операций обходит лимит «на запрос» | Лимит считается один раз |

## Сделать

1. Авторизация в каждом резолвере, который отдаёт или меняет данные, теми же правилами, что REST.
2. Лимит глубины, числа узлов и времени. Батч тоже внутри лимита.
3. Интроспекцию на проде выключить или оставить только своим.
4. Ошибки наружу - общий код. Подробности в журнале без секретов.
5. Выключить автоматическое слияние тела запроса в модель. Аргументы мутации - явная схема.
6. Cookie-сессия: CSRF на мутациях, как в `csrf.md`.

## Промпт

```text
Если есть GraphQL, закрой резолверы и лимиты.

Каждое поле с данными проверяет право. Включи лимит глубины и сложности, включая батч.
На проде выключи публичную интроспекцию. Ошибки без стека.
Мутации с cookie защити от CSRF. Не дай аргументам мутации записывать поля вне схемы.

Если GraphQL нет - не добавляй его. Не пиши примеры тяжёлых вредоносных запросов.
```

## Готово, когда

- [ ] Вложенные объекты не обходят права
- [ ] Есть предел сложности
- [ ] Прод без открытой интроспекции
- [ ] Мутации не принимают лишние поля
