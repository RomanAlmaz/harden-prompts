# HTTP API

API - та же система, без защиты «у нас же есть фронт». Каждый метод проверяет вход, право и лимит. Ошибка не рассказывает устройство сервера.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Маршрут без аутентификации, хотя данные не публичные | Данные читаются напрямую |
| Метод меняет данные и висит на GET | Его дёргают ссылкой и предзагрузкой |
| Включены лишние методы и TRACE/отладка | Лишняя поверхность |
| Версия API забыта без тех же проверок | Старый `/v1` обходит новый контроль |
| Массовый идентификатор в одном запросе без лимита | Один вызов вытаскивает тысячи чужих id, если права проверяют не у каждого |
| Документация и консоль включены на проде без защиты | Видно всю карту API |
| CORS широкий | См. отдельный файл |

## Сделать

1. Инвентаризация маршрутов: метод, кто зовёт, какое право, какая схема тела. Маршрут без записи в этот список не считается готовым.
2. Изменения - не GET. Идемпотентность там, где повтор опасен: платежи, письма, создание.
3. Пагинация обязательна на списках. Потолок размера страницы.
4. Старые версии либо закрыты, либо с теми же контролями.
5. Отладочные консоли и подробные ошибки выключены в проде.
6. Ответы не содержат лишних полей модели. Схема ответа отдельная.
7. Лимит частоты - `rate-limit.md`. Права - `authorization.md` и `idor.md`.

## Промпт

```text
Собери список HTTP-маршрутов и закрой те, что отдают или меняют данные без проверки.

Для каждого маршрута: аутентификация, право, схема входа, схема выхода, лимит.
Списки пагинируй. Изменения не вешай на GET. Повторы опасных команд сделай идемпотентными.
Выключи отладочную документацию на проде или закрой её доступом.
Не возвращай лишние поля и стек.

Не пиши обход API. Если маршрутов сотни, начни с входа, оплаты, файлов и админки, затем остальные, и не называй работу законченной, пока список дыр не пуст или не отдан человеку.
```

## Готово, когда

- [ ] У непубличных маршрутов есть проверка на сервере
- [ ] Списки ограничены по размеру
- [ ] Прод без открытой отладочной консоли
- [ ] Опасный повтор не дублирует действие
