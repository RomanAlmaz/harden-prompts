# Лимиты частоты

Лимит делает массовые действия дорогими: вход, сброс пароля, SMS, создание заказов, поиск. Он не заменяет проверку прав. Слишком жёсткий лимит сам становится отказом в обслуживании.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Дорогие действия без лимита | Коды и письма рассылаются пачками, вход перебирается |
| Лимит только в браузере | Прямой вызов API его не видит |
| Общий лимит на всех за одним NAT | Один человек выключает офис или мобильного оператора |
| Лимит считает успешные и опасные действия одинаково слабо | Опасное остаётся дешёвым |
| Ответ подробно говорит, сколько попыток осталось у чужой учётки | Этим подтверждают, что учётка есть |
| Лимит хранится только в памяти одного процесса | Второй экземпляр приложения лимита не видит |

## Сделать

1. Отдельные лимиты на вход, сброс, регистрацию, отправку кода, создание платежа и тяжёлый поиск. Ключ - учётка, где она есть, плюс более грубый ключ источника.
2. Хранить счётчик так, чтобы все экземпляры приложения его видели, если их больше одного.
3. При превышении - спокойный отказ и журнал. Не раскрывать лишним различием, существует ли учётка.
4. Легальный человек должен иметь путь: подождать или доказать владение почтой. Не делать вечный бан с первого раза.
5. Дорогие внешние API (SMS, почта, шлюз) ограничить и на деньги: потолок в сутки.
6. Не считать лимит заменой авторизации.

## Промпт

```text
Поставь серверные лимиты на дорогие и чувствительные действия: вход, коды, регистрацию, сброс, платежные создания, тяжёлые поиск и экспорт.

Ключ лимита выбирай так, чтобы нельзя было без конца бить одну учётку с разных адресов, и чтобы один общий NAT не лег мгновенно.
Счётчик должен быть общим для всех экземпляров приложения.
Ответ не должен помогать перечислять учётки.
Не ставь вечную блокировку без пути восстановления.

Не подбирай порог атакой по боевому стенду. Если порог неочевиден - вынеси его в конфиг и пометь, что его должен утвердить человек.
```

## Готово, когда

- [ ] Вход, коды и сброс ограничены на сервере
- [ ] Лимит общий для экземпляров
- [ ] Отказ не палит существование учётки
- [ ] Есть потолок на платные внешние вызовы
