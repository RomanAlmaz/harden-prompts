# Чужой фрейм вокруг страницы

Чужой сайт вкладывает твою страницу в невидимый фрейм и ловит нажатия. Заголовок запрета вложения это режет. Спрятанная проверка на фронте без заголовка не режет.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Нет `frame-ancestors` и нет `X-Frame-Options` | Страницу входа и оплаты вкладывают куда угодно |
| Запрет есть только на HTML, а действие висит на маршруте без него | Вкладывают тот экран, где заголовка нет |
| Разрешены все предки `*` | Запрета нет |
| Виджет «нас можно встроить всем» включён по умолчанию | Продукт сам разрешил чужие страницы |

## Сделать

1. `Content-Security-Policy: frame-ancestors` со списком своих родителей или `'none'`. Дублировать `X-Frame-Options: DENY` либо `SAMEORIGIN`, пока CSP не на всех ответах.
2. Один и тот же заголовок на страницах входа, оплаты, настроек и на ответах, которые эти страницы отдают.
3. Если продукт встраивается у партнёров, список родителей точный, не звезда. Партнёр без записи в списке не вкладывает.
4. Не считать защитой скрипт, который пытается выпрыгнуть из фрейма. Его легко не выполнить.
5. Согласовать с `csp.md` и `security-headers.md`, не включить две противоречащие политики.

## Промпт

```text
Запрети вложение страниц в чужой фрейм.

Поставь frame-ancestors none или точный список своих родителей. Добавь X-Frame-Options DENY или SAMEORIGIN согласованно с этим списком.
Покрой вход, оплату и настройки, не только главную.
Если встраивание нужно партнёрам, заведи явный список. Звезду не ставь.
Не заменяй заголовок скриптом, который ломает фрейм.

Не делай страницу, которая ловит клики.
```

## Готово, когда

- [ ] Чужой сайт не может вложить чувствительные страницы
- [ ] Список родителей не равен звезде
- [ ] Заголовок есть не только на одной странице
- [ ] Политика не спорит с CSP
