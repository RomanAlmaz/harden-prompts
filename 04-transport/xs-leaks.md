# Утечки через поведение браузера

Иногда чужому сайту не нужно прочитать ответ. Ему хватает различия: страница открылась или нет, поиск что-то нашёл, картинка загрузилась. Так узнают состояние аккаунта.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Личный URL открывается чужим окном и по ошибке или размеру видно, есть ли объект | Состояние аккаунта читается без доступа к телу ответа |
| Поиск и ошибки отличаются так сильно, что это видно снаружи | Факт «такая запись есть» утекает |
| Нет изоляции окон там, где продукт это выдержит | Чужое окно держит ссылку на твою вкладку |

## Сделать

1. Личные страницы не должны отличаться «для чужого окна» сильнее, чем одним и тем же отказом. Секреты не класть в URL.
2. Где продукт не встраивается и не открывается всплывающими окнами, выставить `Cross-Origin-Opener-Policy: same-origin`. Ресурсные ответы с личными данными не отдавать чужим страницам: `Cross-Origin-Resource-Policy` по смыслу ресурса.
3. `Cross-Origin-Embedder-Policy` включать только если продукт правда изолирует встроенные ресурсы. Не включать вслепую: сломаются чужие картинки и виджеты.
4. Кадры - по `clickjacking.md`. Кэш - по `web-cache.md`.
5. Если заголовки изоляции ломают оплату или вход через всплывающее окно, не отключать их молча на всех страницах: сузить исключение и записать его.

## Промпт

```text
Уменьши утечки состояния аккаунта через различия ответов и окон, без ломки продукта.

Убери секреты из URL. Личный и отсутствующий объект не должны давать удобно различимый ответ там, где это уже требует файл idor.
Поставь Cross-Origin-Opener-Policy same-origin на страницы, которые не должны сохранять связь с открывшим окном.
Cross-Origin-Embedder-Policy не включай целиком, если из-за него отвалятся легальные виджеты: напиши, где он неуместен.
Не добавляй страницу, которая измеряет чужие ответы.
```

## Готово, когда

- [ ] Секретов нет в URL
- [ ] Окна изолированы там, где продукт это позволяет
- [ ] Исключения из изоляции записаны, а не выключены везде
