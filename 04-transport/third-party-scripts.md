# Чужие скрипты на странице

Скрипт аналитики, чата или тег-менеджера выполняется как код самого сайта. Он видит DOM и может прочитать то, что не закрыто `HttpOnly`. Компрометация поставщика становится компрометацией входа.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Скрипт с чужого домена без фиксации версии | Поставщик или кто-то на его месте меняет код |
| Тег-менеджер может добавить любой новый тег | Рекламный тег получает доступ к странице оплаты |
| Нет SRI там, где скрипт статический | Подмена файла на CDN не заметна |
| Чужой скрипт стоит на странице ввода карты и пароля | Ему доступно всё, что введено в DOM |
| Секреты передаются в query виджета | Они уходят поставщику и в его логи |

## Сделать

1. Список сторонних скриптов короткий. У каждого - зачем он и на каких страницах. На страницах пароля и карты чужих скриптов быть не должно, если платёжный виджет сам не требует свой скрипт, и тогда только он.
2. Статические файлы с CDN: версия в URL и `integrity` (SRI) плюс `crossorigin`. То, что меняется само каждый день, SRI не зафиксирует - такой скрипт не ставить на чувствительные страницы.
3. Тег-менеджер ограничить: кто имеет право публиковать теги, запрет произвольных скриптов на проде, отдельные контейнеры для прода и теста.
4. CSP разрешает только эти хосты, не весь интернет. См. `csp.md`.
5. Виджету отдавать минимум. Не весь объект пользователя и не токен доступа.

## Промпт

```text
Найди сторонние скрипты, тег-менеджеры и виджеты.

Убери их со страниц пароля и ввода карты, кроме официального скрипта платёжного виджета.
Для статических файлов поставь версию и SRI. В CSP оставь только нужные хосты.
Опиши, кто может публиковать теги. Не вставляй токены в URL виджетов.
Если скрипт нельзя убрать, запиши риск и страницу, не придумывай, что риск нулевой.

Не добавляй новые трекеры. Не пиши пример вредоносной подмены скрипта.
```

## Готово, когда

- [ ] На страницах пароля нет лишних чужих скриптов
- [ ] Статические CDN-файлы с SRI, где это возможно
- [ ] CSP не разрешает произвольный хост скриптов
- [ ] Токен не утекает в URL виджета
