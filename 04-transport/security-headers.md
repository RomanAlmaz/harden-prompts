# Заголовки безопасности браузера

Заголовки не чинят дырявый код, но режут класс последствий: чужая страница в iframe, утечка ссылки с токеном, лишние права браузера, подмена типа файла.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Страницу можно вложить в чужой iframe | Человека кликают по невидимой кнопке поверх своего сайта |
| Нет `nosniff` | Браузер угадывает тип ответа и исполняет его не так, как думал сервер |
| `Referrer` отдаёт полный URL | Токен или код сброса утекает на чужой сайт |
| Лишние разрешения браузера включены | Сайт без нужды получает камеру, микрофон, геолокацию |
| Ошибки и стек светятся заголовками и телом | Видно внутреннее устройство |
| Кэш общего прокси хранит ответ с личными данными | Чужой человек получает чужой экран |

## Сделать

1. `Content-Security-Policy` - отдельным файлом `csp.md`, не одной дырявой строкой `*` на всё.
2. Запрет вложения: `frame-ancestors 'none'` или список своих доменов внутри CSP. Старый `X-Frame-Options: DENY` или `SAMEORIGIN` - дополнительно, если CSP ещё не везде.
3. `X-Content-Type-Options: nosniff`.
4. `Referrer-Policy: no-referrer` на страницах с токенами и как разумный дефолт `strict-origin-when-cross-origin` на остальном, если продукту нужен referrer для аналитики без пути.
5. `Permissions-Policy` закрывает камеру, микрофон, геолокацию и оплату браузера, которые продукт не использует.
6. `Cache-Control: no-store` на ответы с сессией, почтой, заказами и админкой.
7. Убрать технологические заголовки, если это просто и не ломает эксплуатацию. Не считать скрытие версии защитой вместо патчей.
8. HSTS - в `tls.md`. Cookie - в `02-session/session.md`.

## Промпт

```text
Выставь защитные заголовки на HTML и API там, где это отвечает браузеру.

Добавь nosniff, frame-ancestors и согласованный с ним X-Frame-Options, Referrer-Policy, Permissions-Policy под реальные функции продукта и no-store для личных ответов.
CSP не ослабляй до полного разрешения ради тишины в консоли: если политика ещё не готова, заведи отчёт и список дыр, а не unsafe-inline навсегда.
Не отключай заголовки в проде ради удобства. Не пиши страницу-ловушку для проверки кликджекинга как атакующий пример.
```

## Готово, когда

- [ ] Чужой сайт не вкладывает приложение
- [ ] Тип ответа не угадывается
- [ ] Ссылки с секретом не утекают referrer-ом
- [ ] Личные ответы не кэшируются общим кэшем
- [ ] Лишние API браузера выключены
