# Выход и отзыв доступа

Кнопка «Выйти», которая стирает только cookie в одном браузере, оставляет живыми другие вкладки, украденный refresh и сессии на телефоне.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Выход чистит только клиент | Сервер продолжает принимать старый пропуск |
| Нет «выйти везде» | Украденная сессия переживает смену пароля на этом устройстве, если её забыли погасить |
| Смена пароля не трогает refresh | Пароль сменили, а вор обновляет токен |
| Бан пользователя не гасит сессии | Заблокированный человек доживает срок токена |
| Cookie выхода без тех же флагов | Браузер не затирает боевую cookie |
| Выход висит на GET без защиты CSRF | Чужой сайт завершает сессию ссылкой или картинкой |

## Сделать

1. Выход удаляет серверную сессию и refresh текущей семьи токенов, затем отдаёт cookie с истечением и теми же `Secure`, `HttpOnly`, `SameSite`, `Path`.
2. Смена пароля, сброс, отключение пользователя, смена прав вниз - гасят все сессии учётки или все, кроме текущей, если человек только что перелогинился.
3. Кнопка «выйти на всех устройствах» обязательна, если сессий несколько.
4. Выход меняет состояние, поэтому это POST с защитой CSRF, а не GET, который срабатывает от картинки на чужом сайте. Повторный POST безопасен.
5. Повторный выход и выход с уже мёртвой сессией не падают ошибкой 500 и не создают новую пустую сессию с правами.
6. В журнале: кто вышел, какая сессия (id записи, не сырой токен), не писать сам токен.

## Промпт

```text
Сделай выход и отзыв доступа настоящими на сервере.

Выход удаляет текущую сессию и её refresh, затем гасит cookie теми же атрибутами, с которыми её ставили.
Смена пароля, бан и снятие прав гасят остальные сессии этой учётки.
Добавь или почини «выйти везде», если устройств может быть несколько.
Выход не должен срабатывать от чужой картинки: состояние меняет защищённый POST.
Повторный выход безопасен. В лог не пиши сырой токен.

Не описывай кражу сессии. Если серверных сессий нет, а есть только JWT без отзыва - добавь отзыв refresh или явно напиши человеку, что полный выход сейчас невозможен.
```

## Готово, когда

- [ ] После выхода старый id не принимается
- [ ] Смена пароля гасит остальные сессии
- [ ] Есть способ завершить все устройства
- [ ] Выход не делается чужим GET без защиты
