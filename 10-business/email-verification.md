# Подтверждение почты и телефона

Код в письме доказывает, что человек открыл ящик, только если код случайный, одноразовый и не является сессией на все действия.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Код из 4 цифр без лимита | Код перебирают |
| Ссылка подтверждения без срока и на много раз | Старое письмо остаётся входом |
| В письме сразу сессионная cookie или пароль | Почта становится складом пропусков |
| Ответ «адрес занят» или «не занят» без лимита | Адреса перечисляют |
| Смена почты без подтверждения нового и без повторного входа | Аккаунт уводят на чужой ящик |
| Ссылка с кодом светится в логе и Referer | Код утекает |

## Сделать

1. Код или токен из CSPRNG. Для ссылки - от 128 бит. Для короткого цифрового кода - достаточная длина и жёсткий лимит попыток, иначе короткий код не использовать.
2. Хранить хеш, не сам код. Срок - минуты или часы, не недели. Один успех гасит код.
3. Подтверждение меняет только флаг контакта или завершает конкретное действие. Не выдаёт вечную админку.
4. Смена почты: свежий вход, письмо на новый адрес, уведомление на старый. Пока новый не подтверждён, старый остаётся для сброса.
5. Одинаковый ответ, где продукт может себе это позволить. Лимит отправки, чтобы письмами не задолбали чужой ящик.
6. `Referrer-Policy` и запрет логировать URL с кодом. Канал письма - HTTPS-ссылка на наш хост.
7. Телефон дороже почты в деньгах на SMS: отдельный потолок отправки.

## Промпт

```text
Усиль подтверждение почты и телефона и смену этих контактов.

Код случайный, в базе только хеш, одноразовый, со сроком. Короткий цифровой код - только с жёстким лимитом попыток.
Подтверждение не должно само выдавать лишние права.
Смена почты требует свежий вход, подтверждение нового адреса и уведомление старого.
Не логируй ссылку с кодом. Ограничь частоту отправки.

Не пиши перебор кодов. Если писем в продукте нет - пропусти.
```

## Готово, когда

- [ ] Код одноразовый, со сроком, в базе не открытым текстом
- [ ] Есть лимит попыток и отправок
- [ ] Смена контакта не уводит аккаунт без подтверждения
- [ ] Код не оседает в логах
