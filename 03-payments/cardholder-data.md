# Данные карты и зона PCI

Магазин, который видит полный номер карты и CVV, хранит то, что платёжные правила запрещают хранить, и расширяет ущерб любой утечки. Этот файл не выдаёт сертификат PCI и не заменяет аудитора.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Номер карты, CVV, PIN или дорожка пишутся в базу, лог или тикет | Утечка приложения становится утечкой карт |
| Карта идёт через свой бэкенд «временно» | Она остаётся в логах прокси, ошибках и бэкапах |
| Маска карты на самом деле полный номер | Поддержка и аналитика видят PAN |
| Ключ шифрования карт лежит рядом с картами | Шифрование не спасает |
| Тестовые карты и боевые карты в одной таблице без среды | Боевые данные оказываются у разработчиков |

## Сделать

1. Не принимать и не хранить CVV, PIN и полную дорожку ни в каком виде, ни временно.
2. Не проводить PAN через свой сервер, если шлюз даёт виджет, hosted fields или редирект. Это обычный способ сузить объём работ по PCI. Юридический объём подтверждает человек, знакомый с программой платёжных карт, не этот промпт.
3. Если PAN уже есть в старой системе и его нельзя убрать сразу: остановить запись новых, вычистить логи и бэкапы по решению человека, в интерфейсе показывать только BIN и последние 4 цифры, остальное не отдавать API. Шифрование в покое отдельным ключом - временная мера, не разрешение копить карты.
4. Поиск по логам: вычистить поля вроде `card`, `pan`, `cvv`, `cvc` из логгера и APM.
5. Ошибки пользователю не эхом отдают номер.
6. Доступ к любым остаткам платёжных данных - отдельное право, журнал чтения, не общая админка.

## Промпт

```text
Найди места, где проект касается номера карты, CVV, PIN или магнитной дорожки: формы, логи, модели, админка, ошибки.

Прекрати собирать и хранить CVV, PIN и дорожку.
Переведи приём карты на виджет или страницу шлюза, если интеграция это позволяет, чтобы PAN не шёл через наш сервер.
Вычисти эти поля из логов и ответов об ошибках. В API не отдавай полный номер.
Если полное удаление старых PAN требует решения человека - не выдумывай соответствие PCI, перечисли находки и остановись на них.

Не копируй найденные номера в отчёт, тикет и тесты. Замаскируй.
```

## Готово, когда

- [ ] CVV, PIN и дорожка нигде не сохраняются
- [ ] Новые платежи не везут PAN через свой сервер без явной причины
- [ ] Логи и ошибки не содержат полного номера
- [ ] В отчёте нет живых номеров карт
