# Вход через SAML

Утверждение SAML подтверждает вход только после проверки подписи, адресата и срока. Читать роли из XML до проверки подписи нельзя.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Принимается утверждение без подписи или с чужой подписью | Кто угодно присылает вход за другого человека |
| Не сверяются получатель, аудитория и срок | Чужое или старое утверждение принимают здесь |
| Нет связи с исходным запросом входа | Старый ответ IdP завершает новый вход |
| XML-разбор включён с внешними сущностями | Разбор утверждения тянет лишнее. См. `06-input/xxe.md` |
| Комментарии и лишние подписи меняют смысл до проверки | Библиотека читает не тот узел |
| Идентичность берут из почты внутри утверждения | Почту подменяют, если она не входит в подписанную и проверенную часть |

## Сделать

1. Проверенная библиотека SAML. Не разбирать утверждение своим XML и не проверять подпись вручную.
2. Отклонять утверждение без годной подписи. Сертификат IdP задан в конфиге, не берётся из самого утверждения как единственный источник доверия.
3. Сверять адресата, аудиторию, окно времени и идентификатор ответа с сохранённым запросом входа. Запрос одноразовый.
4. Идентичность и роли читать только из проверенной подписанной части. Почта не единственный ключ, если продукт связывает аккаунты: использовать устойчивый идентификатор IdP.
5. Отключить внешние сущности у XML-парсера. Лимит размера утверждения.
6. Не логировать утверждение целиком.

## Промпт

```text
Если есть вход через SAML, оставь или переведи его на проверенную библиотеку.

Отклоняй утверждение без подписи. Сертификат IdP бери из конфига.
Проверяй адресата, аудиторию, срок и связь с исходным запросом входа. Запрос одноразовый.
Роли и идентификатор читай только после успешной проверки подписи.
Выключи внешние сущности XML и не логируй утверждение целиком.

Не пиши обход подписи и не разбирай XML своим кодом. Если SAML нет - не добавляй его.
```

## Готово, когда

- [ ] Нет приёма неподписанного утверждения
- [ ] Сертификат IdP не берётся из недоверенного XML
- [ ] Сверяются адресат, аудитория, срок и исходный запрос
- [ ] Внешние сущности XML выключены
