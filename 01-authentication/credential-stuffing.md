# Подбор по утёкшим паролям

Люди повторяют пароли. После чужой утечки те же пары логин/пароль приносят на этот сайт. Защита - не «спрятать форму», а сделать массовый вход дорогим и бесполезным.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Нет лимита на логин | Чужие базы паролей прогоняют по API |
| Лимит только по IP | Запросы раскидывают по многим адресам, а одну учётку всё равно ломают |
| Блокировка навсегда без пути восстановления | Людей выключают намеренно, просто зная их логин |
| Одинаковый пароль не сверяется со списком утечек | Известный пароль принимается |
| Нет второго фактора на ценном аккаунте | Одного пароля хватает |
| Сигнал «много неудач» не логируется | Взлом виден только по жалобе |

## Сделать

1. Счётчик неудач на учётку, не только на IP. Отдельный, более грубый лимит на источник - против шума.
2. Растущая задержка или временная блокировка входа паролем. Сброс пароля и поддержка остаются доступны, иначе блокировка сама становится отказом в обслуживании.
3. Проверка пароля по списку утечек при регистрации и смене. Не отправлять полный пароль третьей стороне: префикс хеша или локальный список.
4. MFA на админку и на аккаунты с деньгами. Для обычных аккаунтов - предлагать и помнить отказ.
5. Логи неудач без пароля: учётка, источник, время, итог. Сигнал людям, если у одной учётки или по всему сайту всплеск.
6. Не строить скрытый тотальный сбор отпечатков браузера «на всякий случай». Если нужен риск-сигнал, описать какие поля, зачем и сколько хранятся. См. `09-data/privacy.md`.
7. Ответы об ошибках не помогают отделить существующую учётку.

## Промпт

```text
Закрой массовый подбор входа и прогон утёкших паролей.

Сделай:
- лимит неудачных входов на учётку и отдельный лимит на источник;
- временную блокировку или растущую задержку, не вечный бан без восстановления;
- проверку пароля по списку утечек при задании пароля, без отправки пароля целиком;
- второй фактор для админки и платёжных аккаунтов, если его ещё нет;
- журнал неудач без секретов и понятное место, где включить тревогу на всплеск.

Не добавляй словари, прокси-листы и код для прогона чужих баз. Не включай тотальный фингерпринтинг. Если входа по паролю нет - пропусти.
```

## Готово, когда

- [ ] Одна учётка не принимает безлимитные попытки с разных IP
- [ ] Новые пароли упираются в блоклист утечек
- [ ] Админка не входит одним паролем
- [ ] Неудачи видны в журнале без самих паролей
