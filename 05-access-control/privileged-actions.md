# Опасные действия и админка

Админка - то же приложение, с теми же дырами и более дорогой ошибкой. Отдельный поддомен без нормального входа только прячет адрес.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Админ ходит общим паролем команды | Увольнение и утечка пароля не отзываются |
| Повышение роли без второго шага | Украденная сессия сотрудника раздаёт права |
| Имперсонация без журнала | Поддержка смотрит и меняет данные незаметно |
| Опасное действие доступно GET-ссылкой | Его запускает предзагрузка или чужая страница |
| Админское API забыли закрыть на «внутреннем» пути | Путь находится и работает |
| Секреты и выгрузки всех пользователей в одном экране без нужды | Лишние люди и лишние логи |

## Сделать

1. Отдельные учётки людям. Общий admin/admin удалить. Права дробные: поддержка не равна суперадмину.
2. Вход в админку: MFA и короткая сессия. Повторный ввод для выдачи прав, имперсонации, массового удаления, смены платёжных реквизитов.
3. Имперсонация: право, причина, срок, заметная плашка, журнал, запрет на смену пароля клиента и на действия с деньгами от его имени, если продукту это не нужно отдельно.
4. Опасные действия - POST с CSRF-защитой и подтверждением. Массовые операции ограничить объёмом.
5. Журнал админки: кто, что, над кем, когда. Без паролей и полных карточных данных.
6. Админка на тех же заголовках и TLS, что основное приложение.

## Промпт

```text
Усиль админку и действия, которые меняют права, деньги или чужие аккаунты.

Убери общие учётки. Включи MFA и короткую сессию для админов.
Выдачу ролей, имперсонацию и массовое удаление закрой отдельным правом и свежим подтверждением.
Пиши журнал этих действий без секретов.
Не оставляй опасное действие на GET.
Если админки нет - проверь, нет ли скрытых маршрутов с теми же возможностями, и перечисли их.

Не создавай чёрный ход и не пиши пароль в репозиторий.
```

## Готово, когда

- [ ] Нет общего пароля админки
- [ ] Админ входит со вторым фактором
- [ ] Выдача прав и имперсонация подтверждаются и журналируются
- [ ] Опасные действия не висят на GET
