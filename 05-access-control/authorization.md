# Проверка прав

Вход отвечает на вопрос «кто это». Права отвечают «можно ли ему это действие над этим объектом». Спрятанная кнопка в интерфейсе вопросом не является.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Проверка только на фронте | API выполняет действие без права |
| Роль приходит в теле или в заголовке от клиента | Человек назначает себе admin |
| Проверили, что человек вошёл, но не проверили объект | Годится любой id |
| Отказ по умолчанию не задан | Новый эндпоинт остаётся открытым |
| Права кэшируются навсегда в токене | Снятая роль ещё действует |
| Сервис доверяет внутреннему заголовку `X-User-Id` | Заголовок может прислать и внешний клиент, если шлюз его не стирает |

## Сделать

1. Каждое действие, которое читает или меняет чужие данные, проверяет право на сервере. По умолчанию отказ.
2. Роль и разрешения загружает сервер из своей базы или из выданного им билета, не из поля запроса.
3. Проверка рядом с действием: «этот субъект может это действие над этим id». Общие middleware «просто залогинен» для этого не хватает.
4. Одинаковая проверка для HTML, JSON, GraphQL и фоновых задач. Джоба не обходит права, подставляя первого админа.
5. Смена прав начинает действовать без долгого ожидания. Короткий срок токена или версия прав.
6. Шлюз затирает входные заголовки с id пользователя и ролью и ставит свои только после своей проверки.
7. Админские маршруты не торчат отдельным секретным путём без проверки. Секретный URL - не пароль.

## Промпт

```text
Построй проверку прав на сервере для каждого маршрута и действия, которое читает или меняет данные.

По умолчанию отказ. Роль не брать из тела запроса и из заголовка, который мог прислать клиент.
Проверяй и действие, и конкретный объект, не только факт входа.
Один и тот же контроль для веба, API и фоновых задач.
Новый эндпоинт без явного правила не должен случайно стать публичным: покажи, как это гарантирует код.
Спрятанную кнопку на фронте почини тоже, но не считай её защитой.

Не пиши обход прав. В конце дай таблицу: маршрут, какое право нужно, где оно проверяется. Дыры, которые не закрыл, не скрывай.
```

## Готово, когда

- [ ] Права проверяет сервер на каждом чувствительном действии
- [ ] Клиент не присылает свою роль
- [ ] Нет доступа к объекту только потому, что человек вошёл
- [ ] Новый маршрут по умолчанию закрыт
- [ ] Есть список маршрутов и требуемых прав
