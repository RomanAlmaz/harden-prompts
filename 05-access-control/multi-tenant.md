# Чужие данные между организациями

Если одним приложением пользуются разные компании, запрос без id контура достаёт чужую строку. Общий админ платформы не должен случайно стать пользователем клиента.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| `tenant_id` берётся из тела или query | Человек подставляет чужую организацию |
| В части запросов фильтр по организации забыли | Список, поиск или отчёт показывает всех |
| Фоновая задача пишет в первый попавшийся контур | Письма и счета уходят не туда |
| Общий кэш ключается только id объекта | Пользователь одной компании получает ответ другой |
| Идентификаторы файлов глобальные без контура | Скачивается чужой файл |
| Поддержка платформы входит в клиента без журнала | Не видно, кто смотрел данные |

## Сделать

1. Контур доступа определять из сессии членства, не из произвольного поля. Смена организации - явное действие, сервер проверяет членство.
2. Каждый запрос к данным клиента содержит контур: в условии запроса или в строке политики. Завести один способ, который легко забыть нельзя (scope репозитория, policy, row-level), и не полагаться на память автора каждого SQL.
3. Кэш, очередь, поиск и объектное хранилище включают id контура в ключ.
4. Тест на изоляцию: две организации, одни и те же номера объектов, кросс-доступ не работает. Тест проверяет отказ, не является инструкцией по обходу.
5. Вход сотрудника платформы в данные клиента - отдельное право, срок, причина, журнал. Без этого режим не делать.

## Промпт

```text
Если приложение обслуживает несколько организаций, закрой протечки между ними.

tenant брать из проверенного членства в сессии, не из тела запроса.
Все выборки, кэш, файлы, поиск и очереди должны нести id контура.
Покажи одно общее место, где условие включается, а не список напоминаний.
Добавь тест двух организаций на отказ кросс-доступа, без описания обхода.
Вход платформенного админа в клиента без журнала не оставляй.

Если организации одна и поле tenant нигде не используется - пропусти и напиши это.
```

## Готово, когда

- [ ] Контур не задаётся клиентом произвольно
- [ ] Запросы к данным фильтруются контуром в одном механизме
- [ ] Кэш и файлы не общие на один id
- [ ] Есть проверка, что чужая организация недоступна
