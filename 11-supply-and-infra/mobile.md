# Мобильное приложение

Клиент в кармане человека всё равно недоверенный. Секрет в приложении извлекается. Проверка «телефон не изменён» не заменяет сервер.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Ключ API с правами сервера зашит в приложение | Ключ достают из сборки |
| Токен лежит в обычном файле или в настройках без защиты платформы | Его читает всё, что имеет доступ к данным приложения |
| Приложение ходит по HTTP | Трафик читается в сети |
| Проверка сертификата выключена | Подставляется чужой узел. См. `04-transport/pinning.md` |
| Решение о праве принимает только приложение | Сервер отдаёт чужие данные |
| Резервная копия телефона забирает токен | Сессия утекает в копию |

## Сделать

1. В приложение не класть серверный секрет. Публичный ключ шлюза допустим, секретный нет.
2. Токен и ключ пользователя хранить в хранилище платформы, которое для этого предназначено, не в обычном файле и не в простом ключе настроек без защиты.
3. Запретить ясный HTTP. Проверку сертификата не отключать.
4. Права, цену и чужие объекты проверяет сервер. Клиент только показывает результат.
5. Экран с секретом не остаётся в снимках задач и в резервной копии, если платформа даёт это выключить.
6. Обфускация и проверка целостности клиента не считаются границей доверия.

## Промпт

```text
Если есть мобильный клиент, убери из него серверные секреты и не доверяй его решениям.

Токен положи в хранилище платформы. Запрети ясный HTTP и отключение проверки сертификата.
Цену, роль и доступ к объекту оставь на сервере.
Не считай проверку модификации телефона защитой API.

Не описывай разбор чужого приложения и не выключай защиту магазина приложений. Если мобильного кода нет - пропусти.
```

## Готово, когда

- [ ] Серверного секрета нет в клиенте
- [ ] Токен не в обычном файле
- [ ] HTTP без TLS для API нет
- [ ] Сервер не верит цене и роли из клиента
