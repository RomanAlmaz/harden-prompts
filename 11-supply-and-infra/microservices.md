# Вызовы между сервисами

«Внутренний» адрес не доказывает, кто вызвал метод. Сервис проверяет вызывающего и не считает заголовок с именем пользователя достаточным, если этот заголовок мог прийти с края сети.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Сервис верит любому, кто достучался до порта | Соседний контейнер или узел зовёт чужие методы |
| Идентичность пользователя пересылают необязательным заголовком | Вызывающий подставляет чужой id |
| Сервис ходит в другой с админским ключом на все задачи | Узкая дыра получает широкие права |
| Нет ограничения, какой метод кому можно | Любой внутренний клиент читает все данные |
| Секреты сервисов лежат в общем конфиге | Утечка одного равна утечке всех |

## Сделать

1. Аутентификация сервиса: рабочая учётная запись платформы, mTLS или подписанный вызов. Одна только общая сеть не считается доказательством.
2. Пользовательский контекст пересылать подписанным утверждением или токеном, который получатель проверяет. Получатель затирает входной заголовок с id и ставит свой после проверки.
3. Ключ сервиса с минимальными правами, отдельный на вызываемого. Не один вечный админ-ключ.
4. Получатель всё равно проверяет право на объект. Доверие к соседнему сервису не отменяет `05-access-control/authorization.md`.
5. Таймаут и лимит на вызов. Ошибка соседа не превращается в полный доступ. См. `09-data/exceptional-conditions.md`.

## Промпт

```text
Если сервисов несколько, проверь, как они узнают друг друга и пользователя.

Не оставляй внутренний метод открытым только потому, что он в приватной сети.
Аутентифицируй вызывающий сервис. Id пользователя не бери из неподписанного заголовка, который мог прийти снаружи.
Сузь права ключа. Получатель проверяет право на объект сам.
Поставь таймаут. Секреты сервисов не складывай в общий файл в git.

Если сервис один - пропусти. Не рисуй новую архитектуру ради этого файла.
```

## Готово, когда

- [ ] Внутренний порт не считается аутентификацией
- [ ] Id пользователя не подделывается голым заголовком
- [ ] Ключ сервиса не админский на всё
- [ ] Получатель проверяет право сам
