# Сборка и выкладка

Пайплайн держит секреты выкладки и подписывает то, что уедет в прод. Широкий `pull_request` от чужого форка не должен получать эти секреты.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Секреты в логе сборки | Любой, кто видит лог, получает ключ |
| Сторонний action под плавающим тегом `@v1` или `@main` | Завтра в теге другой код |
| Пайплайн форка получает секреты прода | Чужой pull request печатает ключ |
| Нет разделения тест/прод | Тестовая ветка выкладывает бой |
| Артефакт сборки подменяется между сборкой и выкладкой | В прод уезжает не то, что проверяли |
| У сборки права писать во все репозитории организации | Лишний простор |

## Сделать

1. Секреты только в хранилище CI. Маскировать. Не печатать окружение целиком.
2. Сторонние действия фиксировать по полному коммиту, не по плавающему имени. Минимальные `permissions` у токенаjob.
3. Секреты прода не доступны задачам, которые запускает форк.
4. Выкладка прода - из защищённой ветки, отдельным шагом, не из каждого pull request.
5. Зависимости ставятся с lock-файла в CI так же, как локально.
6. Если есть подпись артефактов или аттестация сборки - не отключать её.

## Промпт

```text
Проверь конфигурацию CI и выкладки в репозитории.

Сузь права токена. Зафиксируй сторонние actions на коммит. Секреты прода не отдавай сборкам форков и не печатай в лог.
Выкладку прода отдели от произвольного pull request.
Не выводи значения секретов в отчёт. Если CI живёт вне репозитория, перечисли, что нельзя проверить по файлам.
```

## Готово, когда

- [ ] Права пайплайна не безлимитные
- [ ] Чужой форк не получает секреты прода
- [ ] Сторонние шаги не на плавающем теге, либо это отмечено как риск
- [ ] Секреты не печатаются
