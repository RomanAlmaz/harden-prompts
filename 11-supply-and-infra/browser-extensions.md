# Расширение браузера

Расширение видит страницы, которые ему разрешили. Лишнее разрешение и сообщение без проверки отправителя отдают сессию и содержимое чужих сайтов этому коду.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Разрешение на все сайты, хотя нужен один | Расширение читает лишние страницы |
| Секрет лежит в обычном хранилище расширения | Его читает скрипт, который попал в расширение |
| Сообщение от страницы принимается без проверки | Страница командует расширением |
| В страницу вставляется сырой HTML из сети | Разметка исполняется в чужом origin |
| В репозитории ключ магазина расширений | Кто угодно собирает обновление |

## Сделать

1. Права минимальные: только нужные сайты и только нужные API браузера.
2. Секреты и токены не в репозитории. Хранение - механизм расширения, предназначенный для секретов, если платформа его даёт. Не обычный объект настроек без нужды.
3. Сообщения от страницы проверять: источник и схема команды. Неизвестное отбрасывать.
4. Не вставлять непроверенный HTML в чужую страницу. Текст вставлять как текст.
5. Ключ публикации расширения держать у человека в хранилище, не в git.

## Промпт

```text
Если в репозитории есть расширение браузера, сузь права и проверь сообщения.

Оставь только нужные сайты и API. Не храни серверный секрет в коде.
Сообщения от страницы принимай по схеме и только от ожидаемого источника.
Не вставляй сырой HTML в страницу. Ключ публикации убери из git, значение в отчёт не пиши.

Если расширения нет - не создавай его.
```

## Готово, когда

- [ ] Нет права на все сайты без причины
- [ ] Серверного секрета нет в расширении
- [ ] Сообщения от страницы проверяются
- [ ] Ключ публикации не в git
