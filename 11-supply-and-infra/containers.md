# Контейнеры и облачная конфигурация

Образ и манифест - часть приложения. Root в контейнере, секрет в слое образа и открытый порт базы делают остальную работу в коде слабее.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Секрет в `Dockerfile` или `ENV` навсегда в слое | История образа хранит ключ |
| Процесс от root | Ошибка в приложении получает права root в контейнере |
| В образ копируют `.git`, тесты и `.env` | Лишнее уезжает в реестр |
| База и админка опубликованы в мир | До них стучатся помимо приложения |
| Образ `latest` без версии | Неизвестно, что вообще запущено |
| Привилегированный pod и широкие права сервисного аккаунта | Контейнер может больше, чем сервис |

## Сделать

1. Секреты в рантайме из секрет-хранилища, не в `Dockerfile`.
2. Пользователь не root, файловая система приложения только для чтения, где это не ломает легальную запись. Запись - в отдельный каталог.
3. Базовый образ зафиксирован по версии. Не тащить секреты и `.git` в контекст сборки (`.dockerignore`).
4. Наружу только порт приложения. База без публичного адреса.
5. В Kubernetes не выдавать привилегированный режим и лишние права сервисного аккаунта «на всякий случай».
6. Если инфры в репозитории нет - не выдумывать кластер. Сказать, что проверять нечего.

## Промпт

```text
Проверь Dockerfile, compose, манифесты Kubernetes и IaC, если они есть в репозитории.

Убери секреты из образа. Запускай процесс не от root, если базовый образ позволяет. Зафиксируй версию базы образа. Не копируй .env и .git.
Не публикуй базу в мир из compose для примера прода. Сузь явно широкие права.

Не сканируй чужие облака и не применяй манифесты к боевому кластеру. Если файлов инфры нет - пропусти.
```

## Готово, когда

- [ ] В образе нет секретов из репозитория
- [ ] Процесс не обязан быть root
- [ ] Версия базового образа зафиксирована
- [ ] Пример прода не выставляет базу наружу
