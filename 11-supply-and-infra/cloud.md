# Облачные ресурсы

Бакет, очередь и панель управления - часть приложения. Публичное чтение и ключ с правами на весь аккаунт расширяют любую ошибку в коде.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Бакет или контейнер объектов читается и пишется всеми | Файлы и бэкапы доступны без права приложения |
| Ключ доступа долго живёт в CI и на ноутбуке | Утечка ключа равна доступу в аккаунт |
| Группа безопасности открывает базу и админку всему интернету | Обход приложения |
| Журнал облака выключен | Действия с ресурсами нечего разбирать |
| Служебный адрес метаданных доступен без ограничений платформы | Приложение получает роль узла. Запросы по пользовательскому URL закрывает `06-input/ssrf.md` |

## Сделать

1. Объекты по умолчанию закрыты. Публичный объект - явное исключение без персональных данных и секретов.
2. Ключи людей и CI короткоживущие, через роль, не бессменный ключ в файле. Права роли минимальные.
3. База, очередь и админ-панели без публичного адреса, если к ним ходит только приложение.
4. Журнал действий с ресурсами включить там, где это задаётся кодом инфраструктуры. Иначе пункт человеку.
5. Служебные метаданные узла - в режиме платформы, который не отдаёт их одним простым запросом без защиты платформы. Не отключать эту защиту в примере.
6. Не хранить боевой конфиг аккаунта в отчёте.

## Промпт

```text
Проверь манифесты облака в репозитории: бакеты, роли, группы сети, базы.

Закрой публичную запись и лишнее публичное чтение. Сузь роли. Не оставляй бессменный ключ в файлах.
Не открывай базу в интернет из примера прода.
Если включение журнала и режим метаданных задаются вне репозитория, напиши это человеку.
Не входи в боевой аккаунт и не меняй его из этой задачи.

Если облачных файлов нет - пропусти.
```

## Готово, когда

- [ ] В примерах нет публичной записи объектов
- [ ] Роли не на весь аккаунт без причины
- [ ] База из примера прода не открыта всем
- [ ] Боевой доступ не менялся из репозитория
