# Загрузка файлов

Файл от пользователя - это входные данные и иногда программа. Имя, тип и содержимое задаёт не браузер в одиночку. Сервер решает, можно ли это хранить и можно ли это отдавать назад.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Имя файла используется как путь | Запись уезжает из каталога загрузок |
| Верят `Content-Type` от браузера | Исполняемый файл приезжает как картинка |
| Загрузки лежат в каталоге, который сервер исполняет | Загруженный файл запускается как скрипт |
| Нет лимита размера и числа | Диск забивается |
| Картинка без перекодирования | Внутри остаётся активное содержимое, которое браузер потом исполнит |
| Архив распаковывается вслепую | Запись идёт вне папки, файлов слишком много |
| Файл доступен по угадываемому URL без прав | Чужие вложения скачиваются |

## Сделать

1. Лимит размера и числа файлов до записи на диск. Таймаут.
2. Имя от пользователя не использовать в пути. Свой случайный id, расширение только из белого списка, если оно вообще нужно.
3. Тип определять по содержимому, не только по заголовку. Белый список типов под задачу: для аватара - изображения, которые вы перекодируете в простой формат.
4. Каталог загрузок не исполняется веб-сервером. Отдача - отдельным обработчиком с `nosniff` и, для неизвестного содержимого, как вложение, не как страница.
5. Права: кто может скачать, решается как доступ к объекту, не секретностью URL. Секретная случайная ссылка может быть дополнительным слоем для «поделиться», со сроком.
6. Антивирусная или типовая проверка - по возможности, не единственный контроль.
7. Распаковка - по правилам пути из `path-traversal.md`.

## Промпт

```text
Усиль загрузку файлов.

Ограничь размер и количество. Имя пользователя не подставляй в путь: храни случайный id.
Тип проверяй по содержимому и белому списку. Картинки перекодируй. Каталог загрузок не должен исполняться как код.
Отдавай файлы отдельным обработчиком с проверкой прав и nosniff. Чужой файл по голому id не отдавай.
Архивы не распаковывай наружу каталога.

Не добавляй примеры вредоносных файлов и не клади боевые вложения в репозиторий.
```

## Готово, когда

- [ ] Путь не зависит от имени пользователя
- [ ] Есть лимит размера и белый список типов
- [ ] Веб-сервер не исполняет каталог загрузок
- [ ] Скачивание проверяет право
