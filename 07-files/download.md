# Скачивание файлов

Скачивание - то же чтение объекта. Плюс браузер не должен исполнить файл как HTML и не должен открыть путь вне хранилища.

Защитный промпт: имена угроз здесь, чтобы их закрыть. Пошаговых атак нет.

## Уязвимости

| Угроза | Что происходит |
| --- | --- |
| Файл отдаётся как `text/html` или тип угадывается | Содержимое исполняется в нашем origin |
| Имя в `Content-Disposition` не очищено | Ломается заголовок, имя становится командой браузеру |
| Прямая ссылка на бакет без проверки прав | Кто знает URL, тот читает файл |
| Экспорт всех данных без объёма и журнала | Одна кнопка выгружает чужие персональные данные |
| Путь из параметра | Читается не тот файл |

## Сделать

1. Доступ по id и проверке права. Для публичных файлов это явное состояние «публичный», не забытая папка.
2. `Content-Type` выставить своим, `X-Content-Type-Options: nosniff`. Неизвестный тип - вложение.
3. Имя скачивания - без перевода строки и кавычек, лучше фиксированное или очищенное базовое имя.
4. Подписанная ссылка в хранилище, если она есть, короткая по сроку и привязана к праву выдать её. Постоянная публичная ссылка на личное - нет.
5. Большой экспорт: право, лимит, журнал, срок жизни файла выгрузки.

## Промпт

```text
Проверь скачивание и экспорт.

Отдавай файл по id после проверки права. Не собирай путь из параметра.
Ставь свой Content-Type, nosniff и безопасное Content-Disposition.
Подписанные URL делай короткими. Экспорт персональных данных закрой правом и журналом.

Не клади в отчёт живые ссылки на чужие файлы из боевого хранилища.
```

## Готово, когда

- [ ] Нет чтения пути из параметра
- [ ] Перед отдачей есть проверка права
- [ ] Браузер не угадывает тип
- [ ] Экспорт личных данных ограничен и журналируется
